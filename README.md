# 🚀 Interview-Preparation

A personal knowledge base of **Java backend interview notes** — every topic is a runnable
Java class with clear comments and a small demo, so you can *read it and run it*. 📚

## 📌 What's Inside

### ☕ Java
Core language notes — JVM, Collections, Multithreading, and Java 8 / Streams.
The foundation everything else builds on.

### 🌱 Spring Framework
IoC, Dependency Injection, beans, and Spring MVC — plus a real, runnable Spring Boot app
showing auto-configuration and starters in action.

### 🧩 Microservices Architecture
How to split apps into independent services, communicate (sync/async), and stay resilient
with patterns like API Gateway, Circuit Breaker, and Saga.

### 🏗️ System Design
High-Level Design fundamentals — scalability, caching, load balancing, rate limiting — and
a simple framework to tackle any design question.

### 🎯 Design Patterns
Reusable GoF solutions — creational, structural, and behavioral — with practical examples.

### 🧱 SOLID Principles
The five principles (SRP, OCP, LSP, ISP, DIP) for writing clean, maintainable code.

**Tech:** Java 17 · Maven · Spring Boot ⚙️
